# speed-test

Простой скрипт для замера скорости интернет-соединения. Выполняет несколько
последовательных HTTP GET запросов к указанному файлу (по умолчанию — тестовый
файл размером 10 МБ), измеряет время каждого запроса и объём скачанных данных,
после чего печатает среднее время запроса и среднюю скорость скачивания в МБ/с.

## Требования

- Python 3.9+
- Зависимости из `requirements.txt`

## Установка

```bash
git clone <URL этого репозитория>
cd speed_test
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

Запуск с параметрами по умолчанию (10 запросов к тестовому файлу 10 МБ):

```bash
python main.py
```

Указать свой URL (например, тяжёлую картинку или файл) и количество запросов:

```bash
python main.py https://example.com/big-image.jpg -n 10
```

Полный список параметров:

```bash
python main.py --help
```

| Параметр          | Описание                                      | По умолчанию |
|-------------------|------------------------------------------------|--------------|
| `url` (позиционный)| URL файла для скачивания                       | тестовый файл 10 МБ |
| `-n`, `--count`    | количество последовательных запросов           | 10 |
| `-t`, `--timeout`  | таймаут одного запроса, секунды                | 30 |


Юнит-тесты используют моки для сети (реальные запросы не выполняются):

```bash
pip install -r requirements-dev.txt
pytest
```

Используются `black` (форматирование), `isort` (сортировка импортов) и

```bash
flake8
```

## Как это работает

1. Скрипт последовательно (не параллельно) выполняет `--count` GET-запросов
   к указанному URL, скачивая ответ потоково (`requests`, `stream=True`),
   чтобы точно замерить время и объём данных без буферизации всего файла в памяти.
2. Для каждого запроса фиксируется время выполнения и число скачанных байт.
3. Ошибки сети по отдельным запросам не прерывают выполнение — они логируются
   в stderr, а итоговая статистика считается по успешным запросам.
4. В конце выводится среднее время запроса, суммарный объём скачанных данных
   и средняя скорость (суммарный объём / суммарное время) в МБ/с.
